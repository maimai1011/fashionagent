# Color matching

- Neutrals—black, white, cream, grey, navy, camel, olive, and denim—anchor a look.
- Monochromatic palettes use value and texture variation so the outfit does not look flat.
- Analogous palettes combine neighboring hues; keep one dominant and the others supporting.
- Complementary hues create contrast; mute or limit one hue to an accent for everyday wear.
- Repeat an accent once in a small accessory when cohesion benefits, but avoid exact matching everywhere.
- Warm/cool mixing is valid when saturation or value provides a shared visual relationship.
- Consider contrast against the wearer's requested coloring only when that information is actually supplied.
